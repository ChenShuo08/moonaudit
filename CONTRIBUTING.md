# Contributing

Thanks for your interest in improving `moonaudit`.

## How to contribute

1. Fork the repo and create a feature branch.
2. Make small, focused changes.
3. Run `moon test tests`.
4. Open a PR with a clear description.

## Dev notes

- Keep CLI behavior backwards compatible.
- Prefer plain-text reports first, then `json`, then `markdown`.
- Add a regression test for each new check.
